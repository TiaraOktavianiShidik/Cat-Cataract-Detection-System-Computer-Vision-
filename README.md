# Cat-Cataract-Detection-System-Computer-Vision-
This project focuses on developing an AI-driven image classification model to detect cataracts in cats. By analyzing eye images, the system provides early detection capabilities to assist in feline healthcare.

## 💻 Code & Implementation
The complete workflow is available in the `.ipynb` file, which includes:
*   **Data Preprocessing:** Resizing, normalizing, and cleaning the dataset to ensure high-quality input.
*   **Data Augmentation:** Techniques applied to expand the dataset and prevent model overfitting.
*   **Model Architecture & Transfer Learning: Implemented Transfer Learning utilizing the MobileNetV2 base model, optimized specifically for mobile deployment. Added custom dense layers and dropout regularization to classify the images accurately into 2 distinct classes (Healthy vs. Cataract).
*   **Training & Evaluation:** Compiling the model and evaluating its precision and recall metrics.

## 🚀 Final Asset
*   **`model.h5`**: The final compiled and trained Keras model, ready for deployment and integration into the mobile application environment.
